# BadApple-ASCII

A simple python tool to render [Bad Apple!!](https://www.youtube.com/watch?v=FtutLA63Cp8) in ASCII through your terminal.

It ain't much, but it's a surprise tool that will help us later.

```bash
# Install dependencies
# pip install numpy opencv-python yt-dlp

# Bad Apple!!
curl https://raw.githubusercontent.com/SinsuSquid/BadApple-VSCode/refs/heads/main/play_bad_apple.py | python3
```
